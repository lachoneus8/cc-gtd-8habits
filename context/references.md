# References

Prior art and related projects worth knowing about while building this out.

## Directly relevant

- **[adagradschool/cc-gtd](https://github.com/adagradschool/cc-gtd)** — the upstream this repo
  forks. GTD engine, Claude Code commands, MCP integrations, private/shareable file split all
  originate there.
- **[pitimon/8-habit-ai-dev](https://github.com/pitimon/8-habit-ai-dev)** — a Claude Code plugin
  applying Covey's *8th Habit* ("Find Your Voice and Inspire Others to Find Theirs") and a
  Body/Mind/Heart/Spirit whole-person assessment to AI-assisted **software development
  workflow** discipline, not personal life/GTD. Not directly reusable here, but relevant once
  this project reaches Habit 7/8: Habit 8's framing (using competence to help others find their
  own voice) lines up closely with this project's own mission (see `personal-untracked/identity.md`), and the
  Body/Mind/Heart/Spirit lens is a plausible elaboration of Habit 7 (Sharpen the Saw)'s
  physical/mental/social-emotional/spiritual dimensions.

## Landscape scan (other GTD-with-AI repos, for structural ideas — none combine 7 Habits + GTD)

- [onlymattjohnson/gtd-skill](https://github.com/onlymattjohnson/gtd-skill) — Claude/Codex/Gemini
  skills that operationalize GTD's clarify step (vague item → next action or project) and the
  natural planning model. Good prior art for AI-assisted clarify/organize.
- [nikhilmaddirala/gtd-cc](https://github.com/nikhilmaddirala/gtd-cc) — broader skills collection
  including Obsidian-vault GTD workflows.
- [git-things-done/template](https://github.com/git-things-done/template) — GTD built on GitHub
  Issues/Actions/Pages instead of local markdown; a different architecture worth knowing exists.
- [iamzifei/gtd-coach-plugin](https://github.com/iamzifei/gtd-coach-plugin) — goal → daily/
  quarterly task breakdown using Claude's memory for persistence.

As of this writing, no public repo was found combining Covey's habits with GTD as a personal,
forkable, AI-assisted system — which is what this repo is attempting.
